# CloudVision Portal Provider

The CVP provider manages Arista CloudVision Portal resources over gRPC/TLS,
built on the Terraform Plugin Framework (protocol 6).

Authentication supports three native methods — `cert` (client mTLS), `session`
(cookie), and `bearer` (rotatable API token, recommended for CI/CD).

## Example usage

```terraform
terraform {
  required_providers {
    cvp = {
      source  = "ioplane/cvp"
      version = "~> 0.1"
    }
  }
}

# Bearer token is recommended for CI/CD (rotatable). Never commit the token —
# source it from the environment / a secret manager.
provider "cvp" {
  endpoint    = "cvp.example.com:443"
  auth_method = "bearer"
  token       = var.cvp_token
}

variable "cvp_token" {
  type      = string
  sensitive = true
}
```

## Schema

### Required

- `auth_method` (String) One of `session`, `cert`, `bearer`.
- `endpoint` (String) CVP gRPC endpoint (e.g. `um-cvp01.infra4.dev:443`).

### Optional

- `ca_pem` (String) Trust root PEM. Optional (defaults to system trust store).
- `cert_pem` (String) Client cert PEM. Required if auth_method=cert.
- `insecure_tls` (Boolean) Skip server cert verification. **Not for production.**
- `key_pem` (String, Sensitive) Client key PEM. Required if auth_method=cert.
- `token` (String, Sensitive) Session cookie or bearer token. Required if auth_method=session|bearer.
